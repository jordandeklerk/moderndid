=============================
ModernDiD 0.3.0 release notes
=============================

ModernDiD 0.3.0 adds three estimators, corrects estimates and standard errors
across most of the existing ones, and removes the Dask, Spark, and Numba code.
Since several arguments have new names, code written for 0.2.0 may need small
changes before it runs. The sections below list those changes first and then
the results that move when you upgrade.

Python 3.12, 3.13, and 3.14 are supported in this release.


Upgrading from 0.2.0
====================

* ModernDiD now requires Python 3.12 or later and Polars 1.38 or later.

  (`#331 <https://github.com/jordandeklerk/moderndid/pull/331>`__)

* The Dask and Spark backends are removed along with the ``dask_*`` and
  ``spark_*`` functions, the ``n_partitions`` argument, and the ``dask`` and
  ``spark`` extras. Estimation runs on one machine, where ``n_jobs`` spreads the
  work over threads and the CuPy backend moves it to a GPU.

  (`#331 <https://github.com/jordandeklerk/moderndid/pull/331>`__,
  `#332 <https://github.com/jordandeklerk/moderndid/pull/332>`__)

* Every function that took ``alp`` now takes ``alpha``. The two-period
  estimators replace ``n_boot``, ``nboot``, and ``n_bootstrap`` with
  ``biters``. ``did_multiplegt`` replaces its percent ``ci_level`` with
  ``alpha``, a probability such as 0.05. Code that still passes one of the old
  names now fails with an error.

  (`#333 <https://github.com/jordandeklerk/moderndid/pull/333>`__,
  `#334 <https://github.com/jordandeklerk/moderndid/pull/334>`__,
  `#335 <https://github.com/jordandeklerk/moderndid/pull/335>`__,
  `#337 <https://github.com/jordandeklerk/moderndid/pull/337>`__,
  `#340 <https://github.com/jordandeklerk/moderndid/pull/340>`__)

* The deprecated generators ``gen_dgp_2periods``, ``gen_dgp_mult_periods``,
  ``gen_dgp_scalable``, ``simulate_cont_did_data``, and
  ``generate_simple_ddd_data`` are removed. Their replacements are
  ``gen_ddd_2periods``, ``gen_ddd_mult_periods``, ``gen_ddd_scalable``,
  ``gen_cont_did_data``, and ``gen_simple_ddd_data``.

  (`#333 <https://github.com/jordandeklerk/moderndid/pull/333>`__)

* With repeated cross-sections, ``est_method="imp"`` and ``"trad"`` in
  ``drdid`` now give the locally efficient estimators of Sant'Anna and Zhao
  (2020). The ``"imp_local"`` and ``"trad_local"`` values that used to select
  them are removed.

  (`#335 <https://github.com/jordandeklerk/moderndid/pull/335>`__)

* Since ``cont_did`` no longer takes ``boot`` or extra keyword arguments, a
  misspelled option now raises an error instead of being ignored. The
  event-time options ``balance_e``, ``min_e``, and ``max_e`` became named
  arguments in the same change.

  (`#340 <https://github.com/jordandeklerk/moderndid/pull/340>`__)

* ``npiv`` and its helpers moved from ``moderndid.didcont.npiv`` to the new
  ``moderndid.npiv`` subpackage. Code that imports ``npiv`` from the top-level
  ``moderndid`` namespace keeps working.

  (`#249 <https://github.com/jordandeklerk/moderndid/pull/249>`__)

* Since the bootstrap helpers are now plain NumPy code that runs as fast as the
  compiled kernels did, the ``numba`` extra is removed.
  ``moderndid.core.numba_utils`` is now ``moderndid.core.bootstrap``.

  (`#372 <https://github.com/jordandeklerk/moderndid/pull/372>`__)

* The ``gpu`` extra now installs ``cupy-cuda12x[ctk]>=14.0`` in place of CuPy 13
  and RMM. Through CuPy's ``ctk`` extra, pip also installs the CUDA libraries it
  needs.

  (`#373 <https://github.com/jordandeklerk/moderndid/pull/373>`__)

* The ``didhonest`` extra requires highspy 1.13 or later. If an upgrade leaves
  an older highspy installed, importing ``moderndid.didhonest`` raises an error
  that asks you to reinstall the extra.

  (`#371 <https://github.com/jordandeklerk/moderndid/pull/371>`__)

* ``to_df`` now returns the time periods of every result as ``Int64`` columns.

  (`#333 <https://github.com/jordandeklerk/moderndid/pull/333>`__)


Changes to estimates and inference
==================================

Results from 0.2.0 that go through the paths below change when you upgrade.
Each change brings an estimate or a standard error in line with the method's
definition.

* Since the multiplier bootstrap in ``att_gt`` and ``aggte`` now sums the
  influence function within clusters, as in Callaway and Sant'Anna (2021,
  Remark 10), clustered standard errors and bands change. When you cluster
  above the unit level, the Wald pre-test is left out because it over-rejects
  at realistic numbers of clusters. ``att_gt`` screens cells for overlap with
  the sampling weights. When a cell's estimation fails, ``att_gt`` skips it and
  warns once. ``aggte`` also fixes its calendar-time rows and its aggregations
  that keep no cells.

  (`#334 <https://github.com/jordandeklerk/moderndid/pull/334>`__)

* The doubly robust estimators for repeated cross-sections now subtract the
  estimation effect of the comparison group's pre-period outcome regression
  from their influence functions, as in Appendix B of Sant'Anna and Zhao
  (2020). While point estimates don't change, standard errors move for doubly
  robust fits with covariates in ``drdid``, ``att_gt``, and ``ddd`` with
  ``panel=False`` or ``allow_unbalanced_panel=True``.

  (`#370 <https://github.com/jordandeklerk/moderndid/pull/370>`__)

* The two-period estimators give the same estimates when you rescale a
  covariate, on the CPU and on the CuPy backend. The fixes also restore the
  Mammen bootstrap draws and give treated units with a propensity score of one
  zero control weight.

  (`#335 <https://github.com/jordandeklerk/moderndid/pull/335>`__)

* ``agg_ddd`` weights cohorts by their eligible treated units, as in
  Ortiz-Villavicencio and Sant'Anna (2025). Its standard errors now include the
  term for the estimated cohort weights. Multi-period ``ddd`` fixes its handling
  of sampling weights and unbalanced panels, the alignment of its influence
  functions, and its GMM and bootstrap standard errors.

  (`#336 <https://github.com/jordandeklerk/moderndid/pull/336>`__)

* ``did_multiplegt`` rewrites its adjustment for control variables, fixes its
  variance and bootstrap computations, and warns when it drops rows with
  missing controls.

  (`#337 <https://github.com/jordandeklerk/moderndid/pull/337>`__)

* With never-treated units coded as ``G = 0`` throughout ``cont_did``,
  ``setup_pte_cont`` now reproduces its results. The bootstrap's band rule and
  pointwise floor are corrected. Since the CCK sieve selection and uniform bands
  now use ``biters`` draws instead of a fixed 999, CCK results shift slightly at
  the same ``random_state``.

  (`#340 <https://github.com/jordandeklerk/moderndid/pull/340>`__,
  `#370 <https://github.com/jordandeklerk/moderndid/pull/370>`__)

* The conditional tests in ``honest_did`` now check every grid point, since the
  accepted set need not be an interval. They also compute truncation bounds that
  rounding can't upset. The restriction matrices for second differences at the reference
  period and for event studies with one post-period are fixed. The covariance
  now comes from influence functions summed within the fit's clusters.
  Restrictions on second differences need two pre-treatment periods and now say
  so with a clear error. A test statistic with zero variance no longer divides
  by zero.

  (`#342 <https://github.com/jordandeklerk/moderndid/pull/342>`__,
  `#363 <https://github.com/jordandeklerk/moderndid/pull/363>`__)

* Without Numba, 0.2.0 computed NaN truncation bounds in ``honest_did`` for
  constraints with a negligible coefficient. Those bounds could drop accepted
  grid points from conditional and hybrid confidence sets under the smoothness
  restrictions.

  (`#372 <https://github.com/jordandeklerk/moderndid/pull/372>`__)

* ``npiv`` gives the instrument basis the same degree and segments in
  estimation as in the selection step and treats ``w`` equal to ``x`` as a
  regression. The fixes also cover the Lepski selection on short or degenerate
  grids, the boundary terms of the spline expansion, and the derivatives for
  additive and generalized-product bases. Band variances now come from row sums
  instead of n-by-n matrices. Memory use on large samples drops as a result.

  (`#345 <https://github.com/jordandeklerk/moderndid/pull/345>`__)

* The CuPy backend no longer crashes or returns silently wrong results for
  singular and rank-deficient designs. It treats them the way the CPU fits do.
  Under the CuPy backend, the weighted bootstraps of ``drdid``, ``ipwdid``, ``ordid``,
  and ``ddd`` run on the CPU because each draw refits small models.

  (`#373 <https://github.com/jordandeklerk/moderndid/pull/373>`__)


New features
============

Extended two-way fixed effects
------------------------------

* ``etwfe`` estimates the extended two-way fixed effects regression of
  Wooldridge (2023, 2025) and comes with the ``etwfe`` extra. ``emfx`` aggregates its cohort-by-period effects into
  overall, group, calendar-time, and event-study summaries with delta-method
  standard errors. The regression can be linear, Poisson, logit, or probit. It
  compares treated cohorts with not-yet-treated or never-treated units and can
  interact treatment with a moderator to study heterogeneous effects.

  (`#250 <https://github.com/jordandeklerk/moderndid/pull/250>`__,
  `#254 <https://github.com/jordandeklerk/moderndid/pull/254>`__,
  `#343 <https://github.com/jordandeklerk/moderndid/pull/343>`__)

Dynamic covariate balancing
---------------------------

* ``dyn_balancing`` comes with the ``diddynamic`` extra and estimates the
  effects of treatment histories that change over time with the dynamic
  covariate balancing method of Viviano and Bradic (2026). Units may select into
  treatment based on their past outcomes and covariates. ``load_acemoglu`` loads
  the democracy and economic growth panel of 141 countries that its guide
  analyzes.

  (`#270 <https://github.com/jordandeklerk/moderndid/pull/270>`__,
  `#341 <https://github.com/jordandeklerk/moderndid/pull/341>`__)

Machine learning DiD
--------------------

* ``didml`` comes with the ``didml`` extra and estimates group-time effects in
  staggered designs with the machine learning approach of Hatamyar, Kreif,
  Rocha, and Huber (2023). ``aggte_didml`` aggregates those effects. By default,
  a bootstrap that refits every cell 100 times gives the standard errors. Under
  ``boot=False`` they come from influence functions instead. Setting
  ``cband=True`` adds a simultaneous band. The ``blp_eventtimes`` and
  ``clan_ttest`` functions describe how the effects vary with covariates.

  (`#295 <https://github.com/jordandeklerk/moderndid/pull/295>`__,
  `#346 <https://github.com/jordandeklerk/moderndid/pull/346>`__,
  `#349 <https://github.com/jordandeklerk/moderndid/pull/349>`__)

Clustered inference
-------------------

* ``att_gt`` and ``ddd`` give analytic cluster-robust standard errors without
  the bootstrap. The estimators warn when clustered inference rests on few
  clusters and name the cluster variable in reports and tables.

  (`#333 <https://github.com/jordandeklerk/moderndid/pull/333>`__,
  `#334 <https://github.com/jordandeklerk/moderndid/pull/334>`__,
  `#336 <https://github.com/jordandeklerk/moderndid/pull/336>`__)

Faster bootstraps and sensitivity analysis
------------------------------------------

* The multiplier bootstrap behind ``att_gt``, ``aggte``, ``ddd``, and
  ``cont_did`` draws its random signs in blocks and multiplies them by the
  influence function matrix. At a million rows, 63 columns, and 999 draws, it
  takes 14 seconds instead of 114.

  (`#371 <https://github.com/jordandeklerk/moderndid/pull/371>`__)

* ``did_multiplegt`` runs the preprocessing that a bootstrap draw can't change
  only once. Its new ``n_jobs`` argument runs the draws on threads without
  changing the results. On the Favara and Imbs data, 200 draws take 12 seconds
  instead of 40, or 2.8 seconds with ``n_jobs=8``.

  (`#371 <https://github.com/jordandeklerk/moderndid/pull/371>`__)

* The conditional tests in ``honest_did`` reuse one HiGHS model per polyhedron
  and warm-start each solve. The relative magnitudes example in the guide takes
  11 seconds instead of 108.

  (`#371 <https://github.com/jordandeklerk/moderndid/pull/371>`__)

Data, plots, and Python versions
--------------------------------

* ``load_fracking`` loads the county employment panel for the fracking
  application in the continuous treatment guides.

  (`#333 <https://github.com/jordandeklerk/moderndid/pull/333>`__)

* The plot themes ``theme_moderndid``, ``theme_publication``, and
  ``theme_minimal`` are exported from the top-level namespace.

  (`#333 <https://github.com/jordandeklerk/moderndid/pull/333>`__)

* Python 3.14 is supported and tested on Ubuntu and Windows.

  (`#375 <https://github.com/jordandeklerk/moderndid/pull/375>`__)

Infrastructure
==============

* The test suite runs in parallel and installs its dependencies with uv.

  (`#364 <https://github.com/jordandeklerk/moderndid/pull/364>`__,
  `#365 <https://github.com/jordandeklerk/moderndid/pull/365>`__)

* Validation tests compare every estimator with a reference implementation of
  its method at full precision. They skip in CI because they need the
  reference packages.

  (`#347 <https://github.com/jordandeklerk/moderndid/pull/347>`__,
  `#348 <https://github.com/jordandeklerk/moderndid/pull/348>`__)

* An asv benchmark suite and a ``spin compare`` command replace the old
  benchmark scripts.

  (`#350 <https://github.com/jordandeklerk/moderndid/pull/350>`__)

* The GPU tests run on an NVIDIA GPU through Modal every Sunday and on manual
  dispatch.

  (`#373 <https://github.com/jordandeklerk/moderndid/pull/373>`__)

* Since pyfixest needs Numba, the ``etwfe`` extra still installs it even though
  ModernDiD's own code no longer uses it.

  (`#372 <https://github.com/jordandeklerk/moderndid/pull/372>`__)
