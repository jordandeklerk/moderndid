===============
Getting Started
===============

**ModernDiD** brings modern difference-in-differences estimators into a single
Python library. Learn the estimate, aggregate, and visualize workflow, then
use it across treatment designs with a consistent API.

   :hidden:

Who it's for
------------

ModernDiD is for applied researchers, economists, and data scientists estimating
causal effects from observational data. If you use DiD packages in R or Stata,
the :doc:`overview` explains how those methods fit into ModernDiD. If you are
new to DiD, begin with the :doc:`causal_inference` introduction.
